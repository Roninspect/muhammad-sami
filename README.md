# Muhammad Sami — Portfolio

Personal portfolio of Muhammad Sami, web developer from Chattogram, Bangladesh.
Built with Next.js (App Router), plain CSS and react-icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

This writes a static site to `out/`. Deploy it to Vercel, Netlify, or upload the `out/` folder to cPanel.

## Edit content

- Page sections: `app/page.js`
- Contact details and links: `lib/content.js`
- Experience entries: `components/Experience.js`
- Styles: `app/globals.css`
- Project screenshots: `public/work/`
